# 🎒 GearUp — Outdoor & Sports Gear Rental (Frontend)

**GearUp** হল একটি প্ল্যাটফর্ম যার মাধ্যমে ব্যবহারকারীরা সহজেই স্পোর্টস এবং আউটডোর অ্যাডভেঞ্চার গিয়ার ভাড়ায় নিতে পারেন। এটি প্রজেক্টের ফ্রন্টএন্ড অংশ, যা একটি রেসপন্সিভ এবং ইন্টারঅ্যাক্টিভ ইউজার ইন্টারফেস প্রদান করে।

---

## 🚀 টেকনোলজি স্ট্যাক (Tech Stack)

* **Framework:** React / Next.js
* **Styling:** Tailwind CSS / Bootstrap
* **State Management & Data Fetching:** React Query / Context API / Axios
* **Icons & Animation:** Lucide Icons / Framer Motion

---

## ✨ ফিচারসমূহ (Features)

* **ইউজার অথেনটিকেশন:** সাইন আপ, লগইন এবং রুল-বেসড এক্সেস (User / Admin)।
* **গিয়ার ক্যাটালগ:** স্পোর্টস ও আউটডোর ইকুইপমেন্টের ক্যাটাগরি অনুযায়ী ফিল্টারিং ও সার্চ সুবিধা।
* **রেন্টাল বুকিং ম্যানেজমেন্ট:** বুকিং ডেট সিলেক্ট করা এবং রেন্টাল অর্ডার সাবমিট করা।
* **ইন্টারেক্টিভ ড্যাশবোর্ড:**
  * **User Dashboard:** বর্তমান রেন্টাল অর্ডার হিস্ট্রি এবং স্ট্যাটাস ট্র্যাক করা।
  * **Admin Dashboard:** গিয়ার আইটেম যোগ/সম্পাদনা/মুছে ফেলা এবং ইউজারদের বুকিং ম্যানেজ করা।
* **রেসপন্সিভ ডিজাইন:** মোবাইল, ট্যাবলেট এবং ডেসটপ সব ডিভাইসের জন্য অপটিমাইজড।
